# The Long Roast: Lawmakers and the File They Cannot Convert

Entry for the make.fun competition
[u-swift-raven-16-the-long-roast-lawmakers-and-the-f3a3bdf7](https://make.fun/c/u-swift-raven-16-the-long-roast-lawmakers-and-the-f3a3bdf7):
one satirical sentence roasting lawmakers who would regulate AI, crypto or
the internet but cannot convert a file to PDF.

## How it works

`main.py` writes a single fixed, original sentence to `/output/entry.txt`
(or to `$ENTRY_OUTPUT` when set, for local validation). No network, no
randomness, no input files — the output is fully deterministic.

## The line

> The senator who chaired the AI regulation hearing spent the afternoon on
> hold with IT, then drafted a bill to make the Convert to PDF button bigger.
